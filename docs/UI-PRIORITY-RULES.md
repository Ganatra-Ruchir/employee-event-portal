# Portal information priority

Apply to every role and page, not only the employee dashboard.

- Dashboard: KPI summary first; analytics and trends second; daily task queue and upcoming commitments next; long histories and supplementary information last.
- Operational pages: put their primary task or frequently used list immediately after the heading; filters and actions beside the relevant content, not on another duplicate page.
- Settings, hierarchy and rare configuration belong at the bottom of navigation or in their own page.
- Each create/edit/manage action has one owner page. Dashboards may summarize items but must not repeat the management form.
- Compact spacing, responsive grids, accessible charts and honest empty states. No invented impact totals; distinguish confirmed attendance from RSVPs.
- Employee dashboard specifically: KPIs → pie attendance outcome → polar SDG engagement → monthly bar chart → registered upcoming events → contribution history. SDG engagement counts verified events by one explicit primary goal, excluding untagged events and reporting them separately. Demo goals are illustrative assignments. No database integration during the preview phase.

## Elixir visual identity

Logo colors: green #51C220, pink #EC1E82, charcoal #383536. Use light grey/white surfaces, dark accessible green for main actions, and restrained pink for navigation accents, selected secondary elements, labels and notification counts. Use darker shades for small text. Avoid blue/navy and decorative gradients. Preserve meaningful attendance, error, success and official SDG color distinctions. Keep all role layouts and single-action ownership unchanged.

## Layout density contract

Authenticated pages use all width remaining after navigation, with 14px desktop gutters and 8–10px mobile gutters; do not reintroduce centered maximum-width wrappers. Use 10px section/grid gaps and 4px label-to-input spacing, not both a grid gap and individual field margins. Align sibling controls, left-align table text, wrap long names and protect mobile tables with local scrolling. Keep dashboard KPIs before charts and histories. Display the leading SDGs directly; remaining goals expandable without an internal scrollbar. Keep touch targets, readable line heights, chart colors and speaker photo aspect ratios intact. Narrow single-purpose security forms can remain centered for readability.
